# My Gym Log

Stwórz dla mnie stronę na której będę mógł każdego dnia wpisywać swoje treningi, ile serii oraz ile powtórzeń z jakim ciężarem zrobiłem, np:

1.Ława płaska wyciskanie sztanga

1- 4x87.5kg

2- 8x77.5kg

3- 8x77.5kg



2.Wiosłowanie jednorącz

1- 10x50kg

2- 8x60kg

3- 10x50kg



5.Rozpiętki butterfly

1- 10x75kg

2- 10x67,5kg

3- 7x67.5kg dropsetx2 do odciny



4.Ściąganie wyciąg górny chwyt neutralny

1- 10x60kg

2- 10x60kg

3- 10x60kg



3.Ława dodatnia wyciskanie sztanga

1- 9x60kg

2- 9x60kg

3- 6x50kg



6.Ściąganie na ramionach

1- 10x67.5kg

2- 10x67.5kg

3- 10x67.5kg

Daj opcje żebym mógł codziennie aktualizować te dane poprzez wpisanie danych, przy każdym ćwiczeniu daj miejsce na zdjęcie bym mógł dodać ze swojej galerii.

Ogólny rozkład treningowy wygląda tak:

Poniedziałek i czwartek; ręce i barki

Wtorek i piątek; nogi i brzuch

Środa i sobota; klata i plecy

Niedziela; brzuch

Pokazuj przy każdych ćwiczeniach progress procentowy który uwzględnia wzrost lub spadek powtórzeń/ciężaru
